Обновление, которое ждали более 1000 лет.
Доска — 16 столбцов × 8 рядов (две доски 8×8, сросшиеся боком). Слева белые против чёрных, справа жёлтые против серых — обычная расстановка.

Команда «Белые + Жёлтые» играет против «Чёрные + Серые». Ходы по кругу: белые → чёрные → жёлтые → серые → снова белые.

Режим игры: 2 игрока (1 против 1 — у каждого по два цвета), 3 игрока (1 против 2 — один играет за двоих), 4 игрока (2 против 2 — у каждого свой цвет), 4 игрока — Каждый сам за себя (Без команд — все против всех, у каждого свой цвет).

Фигуры ходят по стандартным шахматным правилам, свободно по всей доске. Работают рокировка, превращение пешки, шах, но мата нет: побеждает тот, чей король останется последним живым, а фигуры взятого короля переходят под контроль того, кто его взял. Планирования двойного удара, полная свобода хода, фактического убийства короля и непредсказуемые новые комбинации дарят новые ощущения.
